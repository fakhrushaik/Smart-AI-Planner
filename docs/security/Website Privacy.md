# Privacy & Security Review

## Current Privacy Protections

The current privacy page already provides several important disclosures.

These include:

- Planner information is stored in the user's browser.
- Device saving is optional.
- Users can edit and delete planner information.
- Users can export events and tasks.
- Browser storage is not described as an encrypted vault.
- Users are warned against storing highly sensitive information.
- GitHub hosting is disclosed.
- Users are warned not to submit sensitive information through public GitHub issues.
- The current preview states that planner entries are not sent to an AI provider.
- The notice does not claim universal FERPA, GDPR, CCPA, or other legal compliance.

## Data We Do Not Intend to Collect

The current static preview should not be used to collect highly sensitive information such as:

- Passwords
- Authentication credentials
- Payment information
- Financial account information
- Medical records
- Social Security numbers
- Other confidential records

Users should be clearly warned not to enter highly sensitive information into planner fields.

## Browser Storage

Planner information may exist temporarily in the current browser session.

If the user enables device saving, planner information may also be stored using browser local storage.

### Security Requirement

Browser local storage must not be represented as secure encrypted storage.

Users should be informed that:

- Anyone with access to the same browser profile may potentially access saved information.
- Clearing website data may remove locally stored planner information.
- Other open planner tabs may retain temporary copies.
- Browser storage should not be used for highly confidential information.

## Data Retention

The privacy notice should clearly explain how long planner information remains available.

### Temporary Data

Planner information that exists only in the current browser session should remain only for the duration supported by the application.

### Saved Data

If device saving is enabled, planner information may remain in browser storage until the user:

- Deletes planner data
- Disables device saving
- Clears the website's stored data

### Exported Data

Exported files remain wherever the user saves or copies them.

Deleting information from Smart Planner does not automatically delete exported copies.
