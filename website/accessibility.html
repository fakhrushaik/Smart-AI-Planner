ACCESSIBILITY

A comfortable space for everyone.

Smart Planner is designed toward WCAG 2.2 Level AA, with keyboard-friendly controls, readable layouts, and a still, solid display option.

Accessible solid mode

Use solid backgrounds, stronger borders, underlined links, and remove decorative tilts and shadows. This preference applies across the site.

Built-in access

  • Semantic headings, page landmarks, descriptive labels, and a skip-to-content link.
  • Keyboard navigation, visible focus outlines, and native dialogs with Escape-to-close support.
  • Large interactive targets and layouts that reflow on narrow screens and when text is enlarged.
  • Text labels alongside category colors, and announcements for changes and errors.
  • No autoplay, flashing effects, parallax, or essential animation.
  • Support for system reduced-motion, increased-contrast, and forced-color preferences.

On macOS and iPadOS

Use Safari’s page zoom and text controls, a hardware keyboard, or VoiceOver to navigate the site. Events can be edited with buttons; no drag gesture is required. Layouts adapt to portrait, landscape, and smaller window sizes.

We use the web-relevant principles in Apple’s accessibility design guidance. This is a website, not an App Store app. It has not undergone Apple app review and does not claim Apple certification.

Verification and known limitations

The target is WCAG 2.2 AA. Implementation checks are documented in the repository. A full independent accessibility audit and testing with disabled users have not been completed, so conformance is not yet certified.

The planner requires JavaScript. Home, privacy, terms, and this statement work without JavaScript. Native date and time inputs, calendar downloads, and screen-reader announcements can behave differently by browser; VoiceOver and iPad touch testing remain part of the release checklist.

Report a barrier

Report an accessibility issue on GitHub. Include the page, what you were trying to do, and optionally your browser and assistive technology. Do not include personal schedule information. GitHub may require an account.
